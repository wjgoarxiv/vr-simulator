# vr-simulator
::TQQQ VR (Value Rebalancing) 사이클 시뮬레이터:: 

## V1.1 지원 기능 (@2025-03-18 updated)

- [TQQQ](https://kr.investing.com/etfs/proshares-trust-ultrapro-qqq) 대상 VR (Value Rebalancing) 사이클 시뮬레이션
- 각 사이클별 **매수표 / 매도표 확인** (CSV 다운로드 지원)
- 그래프 및 결과 CSV / PNG 파일 다운로드 제공
- **신규!** 현재 상태 기반 즉시 매수/매도표 계산 기능 (이전 기록 무시)
- **신규!** 한국 시간 기준 미국 주식 시장 상태 표시 (주문 가능 여부 확인)
